# Milestone v1.0: Integrasi Docling

**Status:** ✅ SHIPPED 2026-08-07
**Phases:** 1–4
**Total Plans:** 4

## Overview

Perjalanan integrasi Docling untuk meningkatkan akurasi ekstraksi struktur pasal dan tabel dari PDF hukum (PUU). Integrasi dilakukan secara bertahap: penyiapan microservice terpisah, penulisan adapter klien di backend dengan fallback otomatis, pemrosesan output Markdown/tabel terstruktur, hingga tuning parsing artikel oleh LLM dan visualisasi status di UI.

## Milestone Summary

**Key Decisions:**

- Menggunakan Docling via microservice terpisah — menjaga container Next.js ringan, mengisolasi dependensi Python/PyTorch
- Fallback chain otomatis (Docling → pdfjs → pdf-parse → ocr) — zero user-visible errors
- `cleanMarkdownText` table-safe — preserves solitary numeric values inside Markdown table cells
- Penghapusan rawText 100k substring cap dari semua API routes — full Markdown stored in DB
- Prepend fallback warning banner ke rawText — auditable tanpa schema change
- Heuristic Pasal-count validation — catches LLM silent under-parsing
- `extractionMethod` DB column + backfill migration — UI tracing & future per-method QA
- LLM amendment prompt rule — Perubahan regulations only extract changed articles

**Issues Resolved:**

- Multi-column and hierarchical list extraction corrupted by pdfjs reordering → resolved via Docling layout-aware engine
- Markdown table cells with solitary numeric values stripped by aggressive cleaner → resolved via `cleanMarkdownText`
- rawText truncated at 100k chars corrupting large regulation documents → resolved by removing substring limit
- LLM silently returning partial pasal arrays → resolved via heuristic count comparison + regex fallback

**Issues Deferred:**

- OCR-01: Dynamic Docling OCR toggle per PDF type — deferred to v2
- PERF-01: Extraction result caching for repeated PDFs — deferred to v2

**Technical Debt Incurred:**

- `extractionMethod` for Phase 1 (docker infra) records are backfilled null; migration script handles existing records but docker-phase documents predating the column remain null
- Unit test coverage for Docling client HTTP adapter is integration-level only (no mock server)
