</objective>

<threat_model>
## Security Threat Model

- **T-02-01: Resource exhaustion via long-running API requests**
  - **Severity:** High
  - **Mitigation:** Enforce strict 15-second HTTP request timeout via `AbortSignal.timeout(15000)`. If exceeded, abort request and initiate digital fallback chain.
- **T-02-02: Exposure of system/network details in logs**
  - **Severity:** Low
  - **Mitigation:** Only log error statuses, exception messages, and response body context in server stdout/stderr. Do not expose internal network credentials, server paths, or upload buffer details in client response messages.
</threat_model>
