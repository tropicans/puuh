## Accomplishments
- Implemented `cleanMarkdownText` in `src/lib/utils.ts` to strip document headers/footers and page numbers while preserving solitary numbers within Markdown table cells.
- Updated `smartExtractPdfText` in `src/lib/pdf-service.ts` to apply the table-safe `cleanMarkdownText` filter instead of the aggressive `cleanPdfText`.
- Removed `.substring(0, 100000)` constraints from Next.js API routes (`src/app/api/upload/route.ts`, `src/app/api/regulations/fetch/route.ts`, `src/app/api/versions/[id]/reupload/route.ts`) to store full texts in the PostgreSQL `rawText` column.
- Added warning banner prepended directly to `rawText` before database insert in `src/app/api/upload/route.ts` if extraction falls back to non-Docling methods (`pdfjs`, `pdf-parse`, `ocr`).
- Added comprehensive unit and integration test coverage in `src/__tests__/utils.test.ts` and `src/lib/pdf-service.test.ts` to ensure table-safe clean output and fallback detection.
